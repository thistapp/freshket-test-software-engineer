# Freshket - Test for Software Engineer

This is the test for the Freshket Software Engineer homework. The project is written in Node.js and uses Jest for unit testing.

## How to run

1. Install dependencies:

   ```bash
   npm install
   ```

2. Run test:

   ```bash
   npm test
   ```

## Why Jest

I chose Jest as the testing framework because it is an industry standard for Node.js projects. It provides an out-of-the-box experience with zero configuration required. Since it comes with a built-in test runner and assertion library (expect), it keeps the project dependencies minimal and clean compared to using Mocha + Chai.
